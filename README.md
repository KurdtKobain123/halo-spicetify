## Info
A simple theme inspired by the original XBOX theme.

Fonts used: Orbitron and Rajdhani (credits to [Google Fonts](https://fonts.google.com)). An internet connection is needed for the fonts to load.

Created by [@KurdtKobain123](https://github.com/KurdtKobain123)

## Changing Color Schemes

Available schemes: `Spartan`, `Covenant`, `Forerunner`.

Change the scheme with these commands:

```
spicetify config color_scheme <scheme name>
spicetify apply
```
